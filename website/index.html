Vor dem Verbinden

Kompatibilität, ehrlich erklärt.

Windows

Chromium-Browser mit HTTPS können den Ecosys-BLE-Dienst auswählen. Der aktuell geprüfte Windows-Empfänger kennt Datei-Nachrichten über BLE. Ein erfolgreicher Schreibvorgang bestätigt aber nicht, dass die Ziel-App die Datei dauerhaft gespeichert hat.

Android

Die aktuelle Android-App verwendet Bluetooth Classic/RFCOMM und zeigt einen Hello-Test. Browser-Web-Bluetooth spricht BLE, nicht RFCOMM; eine direkte Dateiübergabe an diese Android-App ist daher in dieser Vorschau nicht verfügbar.

iPhone / iPad

Safari stellt Websites kein Web Bluetooth bereit. Du kannst versuchen, Dateien über das iOS-Teilen-Menü an Ecosys zu übergeben. Das nutzt die native Erweiterung – der von dir beschriebene Menüfehler kann dadurch weiterhin auftreten.

Sicherheitsgrenze

Diese Vorschau verwendet den Ecosys-Dateinachrichtenfluss, belegt aber keine vollständige authentifizierte oder verschlüsselte Sitzung. Verwende sie nicht für vertrauliche Dateien. Die Website sendet keine Dateien an einen Webserver.

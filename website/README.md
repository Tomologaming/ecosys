# Ecosys Bridge – statische Website

Dieser Ordner enthält `index.html` als Einstiegspunkt der Website. Die Seite ist eine Browser-Vorschau und ändert keine Dateien in der Ecosys-App. Die verfügbaren Übertragungswege und Plattformgrenzen werden in der Oberfläche erklärt.

## In ein Repository übernehmen

1. ZIP entpacken und den enthaltenen Ordner `website` in das Repository kopieren.
2. Für GitHub Pages den Ordner `website` als Veröffentlichungsquelle in einer GitHub-Actions-Workflow-Konfiguration verwenden (Upload-Artefakt-Pfad: `website`). Alternativ den Inhalt in den von Pages konfigurierten Veröffentlichungsordner kopieren.
3. Vor dem Veröffentlichen die Verbindung mit den Zielgeräten testen; diese Website wurde hier nicht auf echter Hardware verifiziert.
